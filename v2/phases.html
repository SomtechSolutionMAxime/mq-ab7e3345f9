Maquette v2 — Vue chargé de projet

v2P-20260810-0001 Écran absent de la v1. Les phases viennent de Vision (référentiel fixe une fois le projet lancé) et sont assignées par le chargé de projet, jamais par le contremaître.

Règles appliquées ici : les heures sont en lecture seule (seule la coordonnatrice bureau peut les modifier) · une journée peut être splittée entre plusieurs phases (le total doit faire 100%) · le chargé de projet peut ajouter une note au rapport sans toucher aux heures.

Itération suivante (cette révision) : trois vues plutôt qu'une seule — Assigner (rapport par rapport, existant), Totaux par phase (où va le temps sur tout le chantier 166) et Explorer une phase (quels rapports/employés composent ce total) — pour que le chargé de projet puisse suivre l'avancement du projet, pas seulement traiter les rapports un par un · quand le split entre phases ne fait pas 100%, un bouton « Compléter à 100% » ajuste directement la dernière ligne au lieu de calculer à la main · chaque phase ajoutée peut être retirée (✕), avec un minimum d'une phase par employé · la note complémentaire est aussi disponible pour la dictée, avec une icône plus discrète.

Rencontre du 24 sept. (Jacob, Pascal) : filtres sur les 3 vues — un sélecteur de rapport sur « Assigner », une période sur « Totaux » et « Explorer » · les heures-machine d'un employé apparaissent maintenant sous ses heures travaillées, avec le même split de phase par défaut — décorrélable via « Répartir différemment » si le gars a fait moins d'heures machine ou une autre répartition · chaque code machine affiche sa description et son numéro Vision (ex. « C06 — Rouleau compacteur (Vision 352) »), pour que l'admin fasse le lien entre le nom terrain et le nom système.
